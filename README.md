A simple Telegram userbot written in Python using the Telethon library.
The bot automatically replies to incoming private messages, sending text, images, and GIFs.

📌 Features

📩 Auto-reply to incoming messages

🖼️ Sending images via URL

🎞️ Sending GIF animations

⚡ Asynchronous operation (async/await)

🔒 Operation via the Telegram API (API_ID + API_HASH)

🛠️ Technologies

Python 3.8+

Telethon

asyncio

🔑 Setup

Before launching, enter your details:

API_ID = 123456

API_HASH = 'your_api_hash'

SESSION_NAME = 'session_name'

📌 You can get the API_ID and API_HASH here:
https://my.telegram.org
